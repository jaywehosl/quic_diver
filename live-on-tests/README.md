# live-on-tests

Боевой клиент к дублированному узлу на :27015 (localhost).
Всё вшито в .exe: адрес узла, authority, токен, полоса BRUTAL. Запуск — двойной
клик, клиент сам поднимается через UAC (нужны права администратора для WinDivert).

Этот узел трогать НЕ будем — стабильная точка для повседневного использования.
Разработка идёт на :443 отдельным сервером.

.exe НЕ коммитится (вшит секретный токен) — см. .gitignore.

## Версии

- `qd-client.exe` — предыдущая сборка.
- `qd-client-v2.exe` — с файлом настроек (`%APPDATA%\QUICDiver\config.json`),
  разделением «сервис живёт всегда / трафик по команде» и UDP-роутингом.
  Токен отдельный (метка `live-v2` в БД узла), поэтому старый клиент продолжает
  работать со своим — можно держать оба и откатиться.

## Пересборка

Токен вшивается при сборке и в репозитории не хранится. Новый выдаётся на узле:

    /root/qd-server-udp -db /root/qd-live.db -add-user -label <метка>

Сборка (BRUTAL — запасное значение: конфиг и панель его перекрывают):

    go build -ldflags "-s -w \
      -X main.builtinServer=localhost:8443 \
      -X main.builtinAuthority=localhost \
      -X main.builtinToken=<токен> \
      -X main.builtinBrutal=700" \
      -o live-on-tests/qd-client-v2.exe ./cmd/qd-client

⚠️ Работающий .exe перезаписать нельзя (файл занят) — собирать под новым именем
или сперва остановить клиента.

⚠️ Останавливать только Ctrl+C (или «Выход» из трея, когда он появится): снятие
процесса крестом или Stop-Process не даёт восстановить системные DNS и прокси —
машина останется без сети.
